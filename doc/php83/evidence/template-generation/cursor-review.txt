## Defeitos (com reprodução)

### 1. `.progress.tmp` residual quebra `persist` e pode impedir gravar `INTERRUPTED_OR_FAILED`

`persist` abre o tmp com modo `'x'`. Se o tmp sobrar (crash entre create e `replace`), o próximo `persist` — inclusive o do `finally` — levanta `FileExistsError`; o status de interrupção em memória **não** chega ao disco.

```text
# repro local (tempdir): após persist OK, criar report.json.progress.tmp stale
# → persist(...) → FileExistsError; on_disk status permanece 'RUNNING'
```

### 2. Saída malformada de `sha256sum` → `IndexError` (não `ValueError` tipado)

Em `identities`, `line.split()[1]` em linha vazia/malformada falha com `IndexError`. Fecha em falha via `except Exception`, mas a mensagem/tipo não é o `ValueError` de drift esperado.

```text
# remote mock stdout='\n\n', exit=0 → identities(...) → IndexError: list index out of range
```

---

## Não-defeitos / by design (observação)

- Lint `255` **não** entra em `failures` (só status desconhecido fora `{0,255}`); goldens/revisão humana ainda obrigatórios.
- Path com `./` (`a/./b.php`) passa em `decode_outputs`; collector só usa path como metadado + stdin de lint, sem write em FS — risco baixo neste desenho.

## Limitações desta review

- Sem execução guest/`systemd-run`, sem stage remota, sem lint PHP real, sem goldens, sem leitura dos ZIPs de archive.
- Achados de **runtime/compatibilidade** = **pending** (`case-plan.status=PREPARED_NOT_EXECUTED`, `runtime_executed=false`).
- Unittests locais ≠ aceitação de aplicação; collector intencionalmente exit **2** / nonacceptance.
