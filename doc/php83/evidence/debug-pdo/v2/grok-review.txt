PHP 7.4 positional forwarding is sound. `func_get_args()` still preserves real arity, the variadic is a 0-indexed list so the string-key copy never runs, and `parent::query(...$args)` stays a packed unpack. The PHP 7.4 error `Cannot unpack array with string keys` is unreachable here.

The remaining hole is PHP 8 only. `func_get_args()` fills any omitted fixed parameter that sits before the last one actually passed, using this signature’s defaults. `query(fetchMode: PDO::FETCH_NUM)` therefore enters the body and forwards `parent::query(null, PDO::FETCH_NUM)`. Native `PDO::query(fetchMode: PDO::FETCH_NUM)` never enters; it is an `ArgumentCountError` for the missing query. On 8.3 the forwarded `null` hits non-nullable `string $query`, so the failure and, in silent mode, the return differ. Named variadic extras are copied on top of that `null`. The fixture never names `fetchMode` without also passing `query`. A passed `fetchMode` of `null` is not the same case: PDO’s own default is already `null`, so that injection would not show up in these row compares.
