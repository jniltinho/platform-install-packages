## Signature and forwarding

`PDO::query` on 8.3 is `query(string $query, ?int $fetchMode = null, mixed ...$fetchModeArgs): PDOStatement|false`. The held change is `query($query = null, ...$fetchModeArgs)`, with the body still taking `func_get_args()`. That is a 7.4-parseable declaration: no union type, no `mixed`, no return type, no attribute. PHP 8.3 accepts the parameters and still reports the missing return type as a deprecation. The override remains officially incompatible; it is no longer a load fatal.

| Risk | Why it matters |
| --- | --- |
| Return type still missing | Candidate stderr deprecates `DebugPDO::query` at line 330. The same file’s `exec` deprecation was already present on the fatal 8.3 run. stderr stays recorded under the stated policy. |
| New parameters are unused | `$query` and `$fetchModeArgs` exist for the declaration. Forwarding still follows `func_get_args()`, which does not include an unpassed default. `query()` therefore still forwards an empty list. A later edit that calls `parent::query($query, ...$fetchModeArgs)` would forward `null` for a zero-argument call. |
| No `fetchMode` parameter | Positional calls unpack into the parent correctly, and column/class results support that. A PHP 8 named call `fetchMode: ...` does not match this signature. `$query` and `$fetchModeArgs` are the only names. |
| Untyped optional SQL | Keeps the 7.4 call boundary for this harness. Non-string SQL is untested; 8.3’s parent will reject it inside the old logging path. |
| `parent` used as a callable | Line 337 deprecates once per `query()` call, seven times, including both failing queries. That matches a single parent dispatch per call, including calls that throw or return `false`. The patch makes this path reachable; the body is unchanged. |
| Other deprecations | `PropelConfiguration` ArrayAccess, `PropelPDO` transaction/attribute/prepare methods, `DebugPDOStatement::bindValue`/`execute`, and `DebugPDO::exec` are pre-existing and outside this one-line patch. They already appear on the original 8.3 fatal run. |

The stock environment module lists omit `pdo_sqlite` on both runtimes, while `sqlite::memory:` ran. The driver was loaded beside that probe. Its identity is not pinned in this JSON.
